这个网站是 MoclifFood 的个人工作台，用来整理技术文章、项目过程和日常分享。

这里会放什么

编程与项目：代码的实现过程、遇到的问题，以及最后为什么这样选择。

学习笔记：把概念、推导和实验中的发现整理下来，方便以后回看。

日常分享：游戏里的片段、偶然的发现，以及普通日子里值得记下的小事。

从旧博客继续

目录中保留着 2025 年的 Hexo 工程。这次继续沿用文章源文件，重新设计网站的布局与阅读体验。最初的 Hello World 仍保留在原来的地址，空白的 CS2 笔记则留作未发布草稿。

先让内容有个家

首版使用 GitHub Pages 托管。文章以 Markdown 保存，主题和构建配置也一起保留。以后换域名或托管平台时，可以把这些内容继续带走。

目前项目区展示的就是这个网站本身。其他项目和日常文章，会在有实际内容后继续加入。
