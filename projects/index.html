MoclifFood 个人网站

这是目前正在建设的项目：一个同时容纳技术文章、学习记录和日常分享的个人网站。

首版基于现有的 Hexo 工程，使用独立定制主题，提供文章筛选、全文关键词搜索、项目介绍与独立日常页面。

文章与页面由 Markdown 管理，网站构建成静态文件，发布到 GitHub Pages。源码与生成结果分开保存，后续可以更换托管平台。
